# Amazing Decora Website

This is a premium, multi-page website for Amazing Decora, built with **HTML, CSS, JavaScript, and Tailwind CSS**.

## How to Run
1.  Simply double-click `index.html` to open the website in your browser.
2.  Navigate through the menu to see Products, About Us, and Contact pages.

## Features
-   **Responsive Design**: Works on mobile, tablet, and desktop.
-   **Premium Aesthetics**: Uses a "forest and earth" color palette suitable for plant products.
-   **Animations**: Smooth fade-in effects on scroll.
-   **Interactive**: Mobile menu, hover effects, and sticky navigation.

## Editing Content
-   Content is found directly in the `.html` files.
-   Images are linked to Unsplash (high-quality stock photos) or local files. You can replace the `.src` attributes with your own product photos.

## Technologies
-   **Tailwind CSS (CDN)**: No installation required.
-   **Google Fonts**: Merriweather (Serif) and Outfit (Sans-serif).
